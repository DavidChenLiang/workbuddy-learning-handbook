# WorkBuddy 学习手册

一本写给「想把活交给 AI 干完」的人的手册。案例驱动，从零基础到上手，**全部内容在一个 HTML 文件里**，零依赖、可离线、可直接分享。

📖 **在线阅读**：<https://davidchenliang.github.io/workbuddy-learning-handbook/>

---

## 这本书讲什么

不是产品说明书，而是一本「怎么用」的书。核心判断标准只有一条：**任务有没有被干到交付**。

| 部分 | 内容 |
|---|---|
| 入门篇 | 第 1 章 它和聊天机器人的本质区别 · 第 2 章 安装与登录 · 第 3 章 第一个任务跑通 |
| 进阶篇 | 第 4 章 三种工作模式 · 第 5 章 任务/空间/对话管理 · 能力框架六层闭环 · 四大实用场景 · 办公三件套 · 专家与技能 |
| 实战篇 | 电商商城原型 · Obsidian 自动化工作流 · ima 知识库 · Excel 数据处理 · 飞书多维表格 · AI 漫画 · 一键部署 · AI 应用搭建 |

每章都配了**操作案例、避坑清单与验收标准**，建议跟着动手，而不是只读。

## 怎么读

```bash
# 方式一：直接下载 index.html，双击用浏览器打开（无需联网）
# 方式二：在线看
open https://davidchenliang.github.io/workbuddy-learning-handbook/
```

- 左侧栏是全书目录，**桌面端固定悬浮**，点章节直达。
- 每章标题下方有「本章」小节导航条，可跳转到具体小节。
- 想存档或打印：`Cmd/Ctrl + P` → 存为 PDF。已做打印样式（去阴影、去侧栏、自动分页）。

## 关于准确性

- 文中所有产品界面均为**示意图重建**，不是真实截图。
- 「六层闭环」框架是作者基于实际使用归纳的理解框架，**不是官方架构文档**；官方对扩展能力的说法是专家 / 技能 / 连接器 / 资料库四类。
- 产品功能与数量类描述随版本变化，请以客户端实际显示为准。
